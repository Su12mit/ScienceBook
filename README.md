🌱 Know-Science Website

A dynamic and informative website that provides blog reports, video streaming, and downloadable content on a variety of scientific topics, including plants, animals, research, and space. The platform is designed to make scientific knowledge accessible and engaging for all users.

✨ Key Features

Diverse Blog Content: 📝 Read detailed reports on topics spanning botany, zoology, research breakthroughs, and space exploration.

Multimedia Access: 🖼️ Download high-quality photographs and PDF reports for offline use.

Video Streaming: 🎥 Stream video blogs directly on the website for an immersive learning experience.

User-Friendly Interface: 📱 A responsive and intuitive design built with Bootstrap ensures a seamless experience on any device.

🛠️ Technologies Used

Backend: PHP

Frontend: HTML, CSS, Bootstrap

Database: MySQL

Server: XAMPP
